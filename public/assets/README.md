# Framepad Assets

## Textures
Place texture overlay PNG files in this directory:
- grain.png
- matte.png
- wood.png
- acrylic.png
- tape.png

All textures should be semi-transparent, seamlessly tileable images.
You can download free textures from https://www.transparenttextures.com/

## Stickers  
Place sticker SVG/PNG files in the stickers subdirectory.
